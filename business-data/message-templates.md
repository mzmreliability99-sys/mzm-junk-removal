# MZM Approved Message Templates

## Mandatory instructions

This file is the source of truth for approved MZM customer-message templates.

1. When the user asks for an approved template stored here, use the text exactly as written.
2. Do not rewrite, improve, shorten, expand, correct, or paraphrase the approved template.
3. Preserve punctuation, paragraph breaks, blank lines, wording, and links exactly.
4. Replace only placeholders explicitly marked as variable.
5. For the Google Review Request template, replace only `[CLIENT_NAME]` with the client's first name.
6. Always show the completed message to the user first.
7. Do not send the message until the user explicitly says to send it.
8. If the requested approved template cannot be found in this file, say that it is not available. Do not invent or reconstruct it from memory.
