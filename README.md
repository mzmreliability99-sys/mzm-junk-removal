# MZM Junk Removal Website

One-page marketing website for **MZM Junk Removal**, a junk removal company based in Roseville, CA, serving the greater Sacramento area.

## About the Business

- **Company:** MZM Junk Removal
- **Founded:** 2026
- **Services:** Residential & commercial junk removal, construction debris, furniture & appliances, yard waste, full-service hauling
- **Service Area:** Roseville, Sacramento, and 12+ surrounding cities
- **Phone:** (279) 239-1800
- **Email:** mzmreliability99@gmail.com
- **Address:** 906 Main St, Roseville, CA 95678

## Tech Stack

- **Framework:** TanStack Start (React + Vite)
- **Styling:** Custom CSS with CSS variables (no Tailwind utility classes used in components)
- **Fonts:** Bebas Neue (display), Barlow + Barlow Condensed (body/UI) — via Google Fonts
- **Routing:** TanStack Router (file-based)
- **Deploy:** Netlify

## Running Locally

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:3000`.

For full Netlify feature emulation (edge functions, forms, etc.):

```bash
netlify dev --port 8889
```
